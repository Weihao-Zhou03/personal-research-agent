# 中文词法基准

`lexical-cases.json` 含12份公开可提交的合成教学资料、36题和逐题必要证据。实验数字均为虚构材料的一部分，不是项目实测质量。涵盖两字中文、英文缩写、中英混合、条件、时间冲突、跨资料比较、无答案和夹带伪指令的材料。

运行：

```sh
node eval/run-lexical.mjs --output test-output/lexical-eval.json
```

先自行创建输出目录，或选用已存在的临时目录。命令使用独立临时SQLite，不读取用户资料、不调用模型、不访问网络。Recall@8按每题必要证据集合的命中比例计算后平均；同一事实出现于多个重叠块不重复计分。输出保存冻结语料、位置、hash、证据排序、耗时、数据hash、索引版本和Git状态。

这是词法回归与质量基线。无答案题检索到相关材料不代表可以回答；回答支持度和正确拒答必须由真实模型与人工核查另外评测，脚本明确标为未验证。小型合成语料的结果不能推广到私人真实资料、模型质量或Watch验收。

## 真实模型运行

下面的命令真实使用模型额度，只发送本文件夹固定公开合成语料；默认不会由CI执行。不读取用户研究库，密钥从指定本机代理配置读取到内存，不打印、不写报告。

```sh
node eval/run-model.mjs --allow-generation --local-proxy --output .runtime/model-eval.json
```

其他同机/云端接口使用 `PERSONAL_AGENT_MODEL_BASE_URL`、`PERSONAL_AGENT_MODEL` 和私有 `PERSONAL_AGENT_MODEL_KEY_FILE`，省略 `--local-proxy`。先检查模型列表，再提交任务；第一个失败/未知默认停止。`--start-id q33`只执行剩余问题；`--continue-structural-errors`允许明确结构错误后继续下一题，但未知请求始终停止，不重发该任务。`--record-public-output`仅适合此固定公开数据，将供应商JSON正文写入报告便于分析，不用于私人材料。

2026-10-21公开结果保存在 `results/model-v1-*.json` 和 `results/model-v2-*.json`，没有删除失败案例。`review-model-2026-10-21.json`逐单元记录实现团队内独立AI初审，**人工审查仍待完成**。v1暴露了应用比设计§8.3额外禁止带引用缺口fact的问题；v2修正后36题中35完成，q32一次调用90秒后结果未知，保留needs_attention且未重发。6道无答案题5道正常说明不足，另1道未知。q13简报标题和首条结论仍缺“单用户串行”条件；完整报告有条件。
