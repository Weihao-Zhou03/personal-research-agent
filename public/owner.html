first connection

先为 Capture 初始化管理员

当前服务还没有启用 SQLite 或管理员身份。请在运行服务的电脑上完成初始化，再以 SQLite 模式启动。

在新 PowerShell 窗口中使用隔离数据目录和端口：

$captureData = Join-Path $env:LOCALAPPDATA 'PersonalResearchAgent\capture-dev'
node scripts/init-owner.mjs --data-dir $captureData
$env:PERSONAL_AGENT_DATA_DIR = $captureData
$env:PERSONAL_AGENT_STORAGE = 'sqlite'
$env:PERSONAL_AGENT_MODE = 'local'
$env:PORT = '4319'
node server.mjs

启动后打开 http://127.0.0.1:4319/owner。初始化脚本会在终端中隐藏输入密码。已有数据请先按项目迁移说明备份和迁移，再使用该数据目录；不要把密码、私钥或 API Key 发到聊天中。
